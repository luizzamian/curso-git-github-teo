git init . -> Cria um repositorio git na pasta atual
git status -> mostra o status do trabalho(de cada arquivo)
git add nome_arquivo -> adiciona arquivo para ser commit
git commit -m "msg" -> faz commit do arquivo que estava para ser
git log -> mostra todo o histórico de commit

## FLUXO DE TRABALHO

1. criar o diretório do projeto
2. iniciar o git dentro do diretório criado (git init .)
3. edita e cria arquivos
4. git status
5. git add <nome_arquivo>
6. git status
7. git commit -m "mensagem"
8. git status
9. volta para o passo 3
